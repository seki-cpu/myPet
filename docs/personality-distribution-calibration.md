# 趣味人格问卷分布校准

## 结论

固定随机种子 `0x5eed1234`、等概率选择每题 A/B/C/D、模拟 100,000 份完整答案时，旧算法的第一结果中灵缇占 80.12%，法斗占 18.87%。这两个犬种合计 98.99%，确认存在系统性偏置。

校准后十二个犬种均能成为第一结果，最高为柴犬 15.43%，最低为柯基 2.70%。灵缇降至 9.17%，法斗降至 5.56%。

| 犬种 | 旧算法 | 校准后 |
| --- | ---: | ---: |
| 柴犬 | 0.07% | 15.43% |
| 拉布拉多 | 0.12% | 10.73% |
| 金毛 | 0.54% | 9.36% |
| 灵缇 | 80.12% | 9.17% |
| 贵宾 | 0.14% | 8.65% |
| 萨摩耶 | 0.10% | 8.62% |
| 比格 | 0.00% | 8.08% |
| 德牧 | 0.03% | 7.93% |
| 边牧 | 0.02% | 7.18% |
| 哈士奇 | 0.00% | 6.59% |
| 法斗 | 18.87% | 5.56% |
| 柯基 | 0.00% | 2.70% |

## 原因

旧算法按每个维度的理论最小值和理论最大值将累计分数缩放到 0-10。题目选项采用稀疏向量，大多数题目不会给某个特征加分；但旧算法仍把这些未涉及该特征的题目计入理论最大值。随机答案因此集中在所有维度的低值区域，距离低能量原型灵缇和法斗最近。

不同特征在题目中出现次数也不同。例如忠诚的随机期望累计值为 1.75，而尽责为 7.25。直接比较累计值会让题目覆盖更多的维度获得更大的隐性权重。

## 校准方式

1. 对每道题、每个特征计算四个选项的平均贡献，将它作为该题的中性基线。
2. 用户选择只计算相对中性基线的偏移，避免“该选项没有涉及某特征”被误判为极低人格值。
3. 用各特征在全部题目中的标准差做自动权重：`weight = 1 / standardDeviation`。题目覆盖多、波动大的特征不会天然压过覆盖少的特征。
4. 犬种原型同样减去十二个犬种的总体平均，再用余弦相似度匹配“特征方向”。
5. 对外展示的 0-10 特征值仍保留，并将等概率随机答案的期望映射为中间值 5。

这次没有为了追求机械均匀而给犬种设置固定概率或随机补偿；同一组答案始终得到同一结果。

## 回归门槛

运行：

```bash
npm run test:distribution
```

脚本默认生成 100,000 份固定种子的答案，同时计算旧算法和当前算法。当前门槛为：

- 每个犬种的第一结果占比不得低于 2%；
- 单一犬种的第一结果占比不得高于 18%；
- 全选 A、全选 B、全选 D 的固定夹具必须分别得到拉布拉多、金毛、柴犬。

可以用 `npm run test:distribution -- --samples=200000` 增加样本数。
