# 适养问卷分布校准

## 测试对象

- 页面：`/quiz?type=suitable`
- 问题数据：`data/suitableQuestions.v2.ts`
- 评分入口：`domain/suitableScoring.v2.ts`
- 随机种子：`0x51a7ab1e`
- 样本数：100,000 份完整答案

## 校准前的问题

旧算法将生活方式适配分设为 50%，并且只惩罚“犬种需求高于用户能力”的情况。只要犬种需求较低，运动、美容和训练维度就容易获得满分。因此低需求的灵缇和法斗在随机答案中天然占优。

| 犬种 | 旧算法第一推荐 |
| --- | ---: |
| 灵缇 | 69.16% |
| 法斗 | 27.20% |
| 柴犬 | 3.27% |
| 其他九种合计 | 0.37% |

灵缇与法斗合计达到 96.36%，确认存在结果垄断。

## 校准方法

1. 每个特征以四个选项的平均贡献为中性基线。
2. 用该特征在全部题目中的标准差进行自动加权：`weight = 1 / standardDeviation`，避免题目覆盖次数形成隐性权重。
3. 用户答案与十二种犬种都相对各自总体平均值进行比较，使用余弦相似度匹配生活方式和偏好的方向。
4. 不使用固定犬种概率，同一组答案始终产生同一结果。
5. 保留硬性不适配惩罚，并提高安全相关权重：
   - 运动能力差距达到 4：减 30 分；
   - 独处时间超过耐受值 3 小时：减 60 分；
   - 美容承受差距达到 5：减 20 分；
   - 训练投入差距达到 5：减 20 分。

适养问卷不会追求完全平均：随机答案包含相互矛盾的生活条件，低需求犬种合理地略占优势。但十二个犬种现在都能成为第一推荐，不再由两个犬种垄断。

## 典型场景夹具

测试同时固定验证以下场景：

- 安静、低运动、低维护：法斗；
- 高活动、高社交、很少独处：哈士奇；
- 稳定、亲人、家庭陪伴：金毛；
- 冒险偏好但经常独处超过六小时：独处条件优先，柴犬。

## 运行方式

```bash
npm run test:suitable-distribution
```

增加样本数：

```bash
npm run test:suitable-distribution -- --samples=200000
```

回归门槛为每个犬种的第一推荐占比在 2%-22% 之间，并且四个典型生活方式夹具全部通过。
